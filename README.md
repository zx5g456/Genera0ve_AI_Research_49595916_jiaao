# Generative AI Research Project

## Project Overview

This is a research project on Generative AI, project number 49595916, led by jiaao. It mainly focuses on the research, experimentation, and data analysis of Generative AI models.

## Project Goals

- Explore the latest developments in Generative AI technology
- Conduct related experiments and data analysis
- Collect and organize research materials and data

## Project Structure

- `Project_logbook.txt` - Project log records
- `README.md` - Project documentation (this file)
- `new folder/` - New folder (to be organized)
- `not sure arrange later/` - Folder to arrange later
- `reference/` - Reference materials
- `research files/` - Research files
- `STUFF/` - Data and code folder
  - `data.csv` - Main data file
  - `more DATA.csv` - Additional data file
  - `otherdata.csv` - Other data file
  - `test.py` - Test code file

## Usage Instructions

1. Clone or download the project locally
2. Check `Project_logbook.txt` to understand project progress
3. Run `test.py` in the `STUFF/` folder for testing
4. Refer to materials in `reference/` and `research files/`

## Dependencies

- Python 3.x
- Relevant data analysis libraries (such as pandas, numpy, etc., determined by imports in test.py)
